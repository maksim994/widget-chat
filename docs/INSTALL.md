# Установка виджета

## 1. Регистрация

1. Откройте личный кабинет (по умолчанию `http://localhost:5173`).
2. Зарегистрируйте компанию или войдите под демо: `admin@demo.local` / `demo1234`.

## 2. Добавление сайта

1. Раздел **Сайты** → **Добавить сайт**.
2. Укажите название, домен и при необходимости ID Яндекс Метрики.
3. Нажмите **Код** и скопируйте скрипт.

## 3. Вставка на сайт

Вставьте код перед `</body>` на всех страницах:

```html
<!-- пример из кабинета -->
<script>...</script>
```

## 4. Операторы

- Добавьте операторов в разделе **Операторы**.
- Оператор должен быть авторизован в кабинете — тогда он считается «онлайн».
- Без онлайн-операторов (или вне рабочих часов) показывается офлайн-форма.

## 5. Настройки виджета

В **Настроить** у сайта:

- Заголовок, приветствие, цвет, позиция (слева/справа)
- Рабочие дни и часы
- Включение/выключение сайта
- Текст офлайн-формы

## Локальная разработка

```bash
npm install
npm run db:push --workspace=@widget/api
npm run db:seed --workspace=@widget/api
npm run dev:api      # :3001
npm run dev:cabinet  # :5173
npm run dev:widget   # :5174
```

Демо виджета: `http://localhost:5174/?key=<publicKey из seed>` (Vite) или код из кабинета с `widget.js` на API (`http://localhost:3001/widget.js`).

Для локальной разработки с кодом из кабинета задайте в `packages/api/.env`:

```
PUBLIC_WIDGET_URL=http://localhost:5174
```

если используете `npm run dev:widget` вместо сборки embed на API.
