# Чеклист пилота MVP

## Подготовка

- [ ] API запущен, `GET /health` возвращает `{ ok: true }`
- [ ] Кабинет открывается, вход под админом/оператором
- [ ] `npm run db:seed` выполнен (или своя компания создана)

## Сайт и виджет

- [ ] Сайт добавлен в разделе «Сайты»
- [ ] Код виджета вставлен на тестовую страницу (или демо `localhost:5174/?key=...`)
- [ ] Виджет отображается, открывается по клику
- [ ] Настройки (цвет, приветствие, позиция) сохраняются и видны после перезагрузки

## Чат

- [ ] Первое сообщение посетителя создаёт диалог в кабинете
- [ ] Запрашивается и сохраняется контакт (имя/email/телефон)
- [ ] Оператор онлайн (вход в кабинет), ответ приходит в виджет в реальном времени
- [ ] Индикатор «Оператор печатает» при наборе ответа в кабинете
- [ ] Диалог можно закрыть и снова открыть

## Офлайн

- [ ] При отсутствии операторов показывается офлайн-форма
- [ ] Заявка видна в кабинете со статусом OFFLINE

## Метрика и аналитика

- [ ] ID счётчика указан в настройках сайта (если нужна Метрика)
- [ ] Цели созданы по [METRIKA.md](./METRIKA.md)
- [ ] Раздел «Аналитика» показывает данные за выбранный период

## Безопасность

- [ ] Оператор другой компании не видит чужие диалоги
- [ ] Неактивный сайт не отдаёт конфиг виджета (404)

## Документация

- [ ] [INSTALL.md](./INSTALL.md) — установка
- [ ] [METRIKA.md](./METRIKA.md) — цели Метрики
- [ ] Раздел «Справка» в кабинете (`/help`)
