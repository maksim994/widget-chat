# Яндекс Метрика

## Подготовка

1. На сайте клиента установлен счётчик Яндекс Метрики (функция `ym` доступна).
2. В кабинете Widget Chat → **Сайты** → **Настроить** → поле **ID счётчика Яндекс Метрики**.

## Цели (reachGoal)

Создайте в Метрике цели типа «JavaScript-событие» с идентификаторами:

| Событие | Когда срабатывает |
|---------|-------------------|
| `chat_widget_shown` | Виджет загружен на странице |
| `chat_widget_opened` | Пользователь открыл чат |
| `chat_first_message_sent` | Первое сообщение посетителя |
| `chat_contact_requested` | Запрошен контакт |
| `chat_contact_submitted` | Контакт оставлен |
| `chat_operator_replied` | Оператор ответил |
| `chat_offline_form_submitted` | Отправлена офлайн-заявка |
| `chat_dialog_closed` | Диалог закрыт |

## Проверка

1. Откройте сайт с Метрикой.
2. Пройдите сценарий чата.
3. В Метрике → **Отчёты** → **Цели** проверьте срабатывания (с задержкой до 24 ч).

## UTM и страницы

URL страницы и UTM-метки сохраняются в карточке диалога в кабинете и учитываются в разделе **Аналитика**.
